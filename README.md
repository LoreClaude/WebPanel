# 6-COD-on-1-PC

Панель для управления шестью окнами на одном ПК: пять окон Chrome (каждое со своим профилем и аккаунтом Boosteroid) и шестое — рабочий стол или любая программа. Переключение по горячим клавишам, сетка живых миниатюр, макросы, детектор по образцу.

## Этапы

| Этап | Что входит | Статус |
|---|---|---|
| 0 | Пробник: проверка, что окнами Chrome можно управлять в фоне | готово |
| 1 | Запуск 5 окон, переключение Num1–Num6, сетка миниатюр, панель на втором мониторе | готово |
| 2 | Макросы: запись, редактор, воспроизведение, наборы настроек; метка над игрой, журнал, kill switch | **сейчас** |
| 3 | Детектор по образцу, мониторинг, автовосстановление | |
| потом | Синхронизация окон, Telegram, Excel | |

## Этап 1: Panel6

Скачай `Panel6.exe` со страницы [Releases → последняя версия](../../releases/latest) (раздел «Assets») и запусти.
Репозиторий приватный: страница и файл открываются, только если ты вошёл на GitHub под своим аккаунтом,
иначе GitHub показывает «404».
Панель откроется на втором мониторе (меняется в настройках) и спрячется в трей, если закрыть её крестиком.
Настройки и журнал лежат в `%APPDATA%\Panel6` (`config.json`, `panel6.log`).

### Первый запуск
1. **Настройки → Клавиши и мониторы**: проверь, какой монитор игровой, а какой для панели.
2. **Запустить все окна**: откроются 5 отдельных Chrome со своими профилями (`%APPDATA%\Panel6\profiles`) и развернутся на весь игровой монитор. В каждом один раз войди в свой аккаунт Boosteroid — дальше вход сохранится.
3. Если какое-то окно вышло из полного экрана, нажми кнопку ⛶ на его карточке.

### Клавиши по умолчанию (меняются в настройках, NumLock должен быть включён)
Назначить можно любую клавишу или сочетание: буквы, цифры, F1–F24, цифровой блок, знаки `- = [ ] ; ' , . / \`.
Клавиша без Ctrl/Alt занята панелью во всех программах: пока панель запущена, она не печатается в чате игры.

| Клавиша | Действие |
|---|---|
| Num1 … Num5 | окна Chrome 1–5 |
| Num6 | шестое окно (рабочий стол или выбранная программа) |
| Num0 | сетка всех окон (открыть/закрыть) |
| Num9 | предыдущее окно (туда-обратно) |
| Num8 / Num7 | следующее / предыдущее по кругу |
| Num+ | старт / пауза основного макроса текущего окна |
| Num− | остановить все макросы |
| Num* | начать / закончить запись макроса в текущем окне |

### Сетка всех окон
Живые миниатюры всех шести окон поверх игрового монитора. Сами окна не меняют размер и не сворачиваются.
- клик, перетаскивание, колесо — уходят в настоящее окно Chrome; клавиши — в выбранное (подсвеченное) окно;
- двойной клик — развернуть окно; Esc или Num0 — закрыть сетку.

### Шестое окно
**Настройки → Окно 6**: «Рабочий стол Windows» или «Окно программы» (по части заголовка, например `Steam`).
Для рабочего стола окна Chrome по умолчанию сдвигаются за край экрана, чтобы игра не замирала; при переключении обратно возвращаются на место.

### Журнал
Внизу панели — журнал событий со временем: запуск и закрытие окон, старт, пауза, остановка и ошибки макросов,
сообщения панели. Предупреждения выделены красным. «Свернуть» оставляет только последнюю строку.
Всё из журнала пишется и в `panel6.log`.

### Метка над игрой
Небольшая полупрозрачная метка поверх окна игры, видна только когда впереди окно игры: номер и название окна,
что делает его макрос, и значки макросов всех окон (▶ идёт, ❚❚ пауза, ⚠ ошибка, ● запись).
Клики проходят сквозь неё, фокус и захват курсора она не забирает. Угол экрана или выключить —
**Настройки → Метка над игрой**.

### Kill switch: закрыть окна при смене подключения
Если подключение к интернету сменилось, панель сразу закрывает окна 1–5: процессы Chrome завершаются,
макросы останавливаются. Рабочий стол и окно 6 не трогаются. Срабатывает, когда:
- сменился путь в интернет — VPN выключился, включился или переподключился, Wi-Fi сменился на кабель,
  связь пропала. Windows сообщает панели о смене маршрутов и адресов сразу, и окна закрываются за доли секунды —
  раньше, чем Chrome начнёт переподключать страницы (сам Chrome реагирует на смену сети с задержкой).
  Эта проверка ничего не отправляет в сеть;
- IPv6 пошёл не через то подключение, что IPv4 (утечка мимо VPN);
- сменился внешний IP — например, VPN переключился на другой сервер с тем же адресом туннеля. Проверка раз в 5 секунд
  запросом к Cloudflare (`1.1.1.1`), если он недоступен — к `api.ipify.org`; после любой смены сети — сразу
  и потом раз в секунду три секунды;
- внешний IP не из разрешённых.

#### Разрешённый внешний IP
В **Настройки → Kill switch → Разрешённый внешний IP** — адрес, с которого можно входить (сейчас `185.163.47.154`;
несколько — через запятую; кнопка «Взять текущий» подставляет нынешний). Тогда:
- окна запускаются только после свежей проверки: внешний IP из списка, а IPv6 не идёт мимо VPN. Без VPN
  или с другим IP окна не запустятся, причина — в журнале;
- уже открытые окна закрываются, как только внешний IP перестаёт совпадать.

Пустое поле — запуск с любого IP.

Самая надёжная защита — включить ещё и kill switch в самом VPN: он перекрывает интернет на уровне системы
в тот же миг, как падает туннель, а Panel6 закрывает окна, чтобы они не переподключились, когда VPN поднимется
на другом сервере.

Включается галочкой **Kill switch** вверху панели, рядом видно текущее подключение и внешний IP.
Частота проверки и проверка внешнего IP — в **Настройки → Kill switch**. Когда защита срабатывает, в журнале
появляется красная строка «что сменилось и какие окна закрыты», а у значка в трее — уведомление.
Когда VPN снова подключён, запусти окна кнопкой «Запустить все окна». Chrome не будет предлагать восстановить
страницы.

Если внешний IP меняется сам (мобильный интернет без VPN), выключи проверку внешнего IP и очисти список разрешённых.

### Если что-то не так
Пришли файл `%APPDATA%\Panel6\panel6.log` и опиши, что делал.

## Этап 2: макросы

Макрос — список шагов, который панель выполняет в окне Chrome сама: клики, перетаскивание, колесо, клавиши,
поворот камеры, паузы и повтор блока шагов. Макросы работают в фоне, в нескольких окнах одновременно,
и не двигают настоящую мышь. Координаты хранятся в долях окна, поэтому макрос не зависит от размера окна.

### Записать макрос
1. Открой окно игры (например, Num1).
2. Нажми **Num*** — пошла запись. Играй как обычно.
3. Снова нажми **Num*** — в текущем наборе появится макрос «Запись ЧЧ:ММ:СС».

Записываются клики, двойные клики, перетаскивания, колесо, нажатия клавиш с их длительностью
и поворот камеры в режиме захвата курсора. Клики при захвате курсора записываются «на месте», без прыжка камеры.
Записывать можно и из окна **Макросы…**: кнопка «● Записать» добавит шаги после выбранного шага.

### Редактор (кнопка «Макросы…»)
- слева — макросы текущего набора; «Новый», «Копия», «Удалить»;
- вкладка **«Шаги»** — список шагов на всю высоту, вкладка **«Параметры»** — название, клавиша запуска
  (в текущем окне или во всех отмеченных; повторное нажатие останавливает), повторы (0 — до остановки),
  пауза между повторами, поведение, когда ты действуешь в окне, и свои повторы для каждого окна;
- для кликов точку можно указать мышью на снимке окна («Указать на снимке окна…»);
- «Пауза перед шагом» — число или интервал: отметь «случайно до», и пауза каждый раз выбирается случайно
  между двумя значениями (в списке шагов видно, например, «100–300 мс»);
- «▶ Проверить» запускает макрос в выбранном окне, «▶ С шага N» — начиная с выделенного шага
  (следующие повторы — с начала), «■ Стоп» — останавливает. Шаг, который идёт сейчас, подсвечен зелёным.

Изменения сохраняются сами.

#### Работа с шагами
Несколько шагов выделяются Shift/Ctrl + клик. Меню по правой кнопке повторяет всё ниже.

| Клавиша | Действие |
|---|---|
| Enter, двойной клик | изменить шаг |
| Del | удалить выделенные |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать, вырезать, вставить — в том числе в другой макрос или набор |
| Ctrl+D | копия выделенных |
| Ctrl+↑ / Ctrl+↓ | переместить выше / ниже |
| Ctrl+Z / Ctrl+Y | отменить / повторить |

#### Обработать запись
Кнопка «Обработать ▾» (и в меню по правой кнопке) работает с выделенными шагами, а если выделено меньше двух —
со всем макросом:
- паузы быстрее ×0,5, медленнее ×2 или на свой множитель (паузы перед шагами и шаги «Пауза»);
- паузы перед шагами случайно ±N %: пауза 200 мс при ±30 % станет случайной от 140 до 260 мс, ритм записи
  сохраняется, шаги без паузы не меняются;
- убрать паузы короче N мс;
- склеить мелкие повороты камеры: запись режет плавный поворот на куски по 50 мс, после склейки поворот тот же,
  а шагов меньше.

Любую обработку можно отменить через Ctrl+Z.

### Случайный ввод
Шаг «Случайный ввод» заданное время через случайные промежутки (например, каждые 50 мс) выполняет случайное действие
из отмеченных: клик, зажать или отпустить кнопку мыши, вести мышь, поворот камеры, колесо, клавиша.
Можно задать область окна (или «на месте курсора» для игры с захватом курсора), кнопки мыши, список клавиш
и сколько их держать, размах поворота камеры и колеса. Всё, что случайный ввод зажал, он сам отпускает в конце.

### Запуск
- на карточке окна выбери **основной макрос** и нажми ▶ (или **Num+** в этом окне; Num+ ещё раз — пауза);
- «Во всех отмеченных окнах» — один макрос сразу во всех отмеченных у него окнах;
- **Num−** или «■ Стоп всё» — аварийная остановка; зажатые макросом клавиши и кнопки отпускаются.

### Когда ты сам действуешь в окне
Если ты двигаешь мышью или жмёшь клавиши в окне, где идёт макрос (или управляешь им через сетку),
макрос по умолчанию встаёт на паузу и продолжает через 1 секунду тишины. В **Настройки → Макросы** можно выбрать
«продолжать» или «остановить» и время тишины; у отдельного макроса — своё поведение.

### Наборы настроек
«Набор» — свои макросы и основной макрос для каждого окна (например, «Фарм» и «Событие»).
Переключаются в списке «Набор», меню «Наборы ▾»: новый, копия, переименовать, удалить, сохранить в файл и загрузить из файла.
Файлы наборов лежат в `%APPDATA%\Panel6\presets`.

## Этап 0: пробник

Пробник запускает несколько отдельных копий Chrome. У каждой своя папка профиля в `%LOCALAPPDATA%\Panel6Probe\profiles`, а твои обычные профили Chrome он не трогает. Затем пробник проверяет, доходят ли клики, клавиши и движения мыши в окно, закрытое другими окнами.

### Как запустить

1. Скачай `Panel6Probe.exe` со страницы [Releases → probe-latest](../../releases/tag/probe-latest).
2. Запусти его. Если Windows SmartScreen предупредит, нажми «Подробнее» → «Выполнить в любом случае»: программа не подписана.
3. На вопрос «Сколько окон» ответь `2` (потом можно попробовать `5`).

### Что сделать

1. **Пункт 1 — автотест.** Окна сами раскроются и будут переключаться, мышь и клавиатуру в это время не трогай. Займёт около минуты.
2. **Пункт 2 — открыть Boosteroid.** В каждом окне один раз войди в свой аккаунт и запусти игру.
3. **Пункт 5 — ручная отправка.** Выбери окно, тип действия (клик / клавиша W / движение мыши) и задержку. За время задержки переключись на *другое* окно и потом проверь, сработало ли действие в игре в фоновом окне. Особенно важно движение мыши: поворачивается ли камера.
4. **Пункт 4 — удержание активности.** Запусти на 20–30 минут и проверь, выкинуло ли Boosteroid за неактивность.
5. **Пункт 6 — нагрузка**, когда игра запущена во всех окнах.
6. **Пункт 7 — отчёт.** Откроется папка. Пришли в чат файл `report_*.txt`, пару снимков из `shots` и коротко опиши, что видел в пункте 5.

Окна Chrome от пробника можно закрывать как обычно. При следующем запуске вход в аккаунты сохранится.
